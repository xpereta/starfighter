# dev

- **Purpose:** tuning panel and debug overlay, so feel can be tuned live (including on preview URLs) while you keep playing. Not gameplay code: nothing in `src/core` imports it.
- **Loading:** a separate lazy chunk. It loads with `?dev` in the URL (always in `npm run dev`). Build with `VITE_DEV_TOOLS=false npm run build` to strip it from the bundle entirely (release builds).
- **Panel (`panel.ts`, rows in `panel-ui.ts`, no library):** about 240 px wide, scrolls, generated from the parameter definitions in `data/tuning` (range, short unit and note come from the definition). Sections: Flight, Evade, Guns, Camera (parameters and toggles), then Presets, Replay, Debug. Pool sizes (`bulletCap`) are not shown: they only apply when the world is created.
  - **One row per parameter:** the bar is a fill inside the row. The text is drawn twice, light on the dark track and dark inside the fill (the dark copy is clipped to the fill width), so the bar sweeps over the text and contrast holds on both sides of the edge. The hovered row has a 1 px outline; the row being dragged has a 2 px outline and a bold, underlined value.
  - **Editing:** drag a bar (it only starts after a few pixels, so double-clicks never change a value; hold Shift for fine control). Double-click the **value** to type it (Enter commits, Esc cancels); double-click the **label** to reset to the default. Values are rounded to a step derived from the range and shown with fixed decimals.
  - **Cross-field rules** (`panel-logic.ts`, `RELATIONS`) hold live: the edited value is clamped and the clamped value is shown (`viewMax >= viewMin`, `minSpeed <= cornerSpeed <= maxSpeed`, `minSpeed <= cruiseSpeed <= maxSpeed`, plus the arena min/max pairs).
  - **Changed values** get a yellow bar on the row's left edge (a shape, not colour alone). "Show only changed" hides everything still at its default.
  - **Tooltips:** hovering a row (label, value or bar) shows, after about 300 ms, a plain-language note: what the setting does, what raising and lowering it does, plus the default and range. It wraps (max about 260 px), sits left of the panel (flips if there is no room) and is also the row's `aria-description`; keyboard focus (Tab) shows it too. Every parameter and toggle has a note: `notes.test.ts` fails if one is missing or too short. Notes live in `data/tuning/*.ts` (`note`) and `tuningToggleNotes` in `data/tuning/index.ts`.
  - **Keys:** `H` hides/shows the panel, `` ` `` toggles the debug overlay, `Esc` hands the keyboard back to the game. After any pointer release, button click or Enter, panel controls drop keyboard focus, so arrows, WASD, Space and Shift keep flying the ship and never nudge a slider. Game keys are only ignored while you are genuinely typing in a text field.
  - **Transparency:** the whole panel is semi-transparent (the "Panel opacity" row, 70-100%, default 85%) and becomes solid under the mouse; rows and bars are opaque. Colours and the minimum opacity are in `panel-style.ts`; `panel-style.test.ts` checks the contrast numerically over bright and dark backdrops (>= 4.5:1; measured worst case 6.4:1 light text on the track and 5.8:1 dark text on the fill at 70% opacity).
- **Presets (`presets.ts`, pure and tested):** save/load by name in browser storage, export/import as a versioned JSON file (validated: unknown keys and out-of-range values are rejected loudly), reset to defaults. **Copy as defaults** copies a list of every value that differs from the committed defaults (`flight.grip: 6 -> 9`); paste it to Claude to commit them into `data/tuning`.
- **Debug overlay (`debug-overlay.ts`, toggle with `` ` `` or the panel):** nose vs velocity vectors, turn-rate curve with the current point, camera center and safe frame, hit circles (targets, bullets, enemy shots, ship), fps/frame time, entity counts.
- **Replay (`replay-controls.ts`, on top of `core/replay`):** Record restarts the run from a fresh seed and records its inputs; Stop keeps it; Play restarts from the recorded seed, applies the recorded tuning and injects the recorded inputs, then restores your tuning and says whether the final state matches; Verify re-runs the recording headless; export/import as a versioned, validated JSON file.
- **Reads/writes:** edits `world.tuning` in place; reads `world` for the overlay.
- **Test:** `panel-logic.test.ts` (labels, steps, decimals, rounding, relations, changed/reset), `panel-style.test.ts` (contrast), `notes.test.ts` (tooltips), `presets.test.ts`; e2e checks the panel is absent without `?dev`, has one row per parameter, typing and double-click reset, drag then focus release, cross-field clamping, `H`, "only changed", tooltip delay and placement, no scaling on high-DPI screens, and the replay round trip.
