# core/run

- **Purpose:** the run as a state machine: start screen, battles 1..`battleCount`, debriefs, end (spec: `docs/specs/prototype-3-pilots.md` section 1). Practice mode (the Prototype 1/2 arena) is the default (`mode: 'practice'`) and nothing here touches it.
- **Status:** implemented (A2). The app enters a run with `enterStartScreen(world)` (I1 wires the boot flow and `?practice`).
- **Contract:** `world.run` = `{ mode, phase, battle, wave, result, cursor, hull, waveTotal, hitsSeen, battleKills, battleLost, candidates, available, selectedVeterans }`. Anything you add must go into `mixRun` (replay hash; arrays need an explicit check in `hash-coverage.test.ts`).
  - `candidates` (`PilotTemplate[]`: name and trait): the generated pilots offered at a debrief (`pickCount`), empty outside a debrief, once one was picked, and when the squad is full. Generated with A1's seeded generator when the debrief opens.
  - `available` (`OfferedVeteran[]`: a template plus the save's veteran `id`): the saved veterans shown on the Start screen. Set by the app with `offerVeterans(world, veterans)`; meta itself is not world state. `selectedVeterans` holds the ticked ids, at most `veteransPerRun`.
  - `cursor` is the highlighted row; `menuRows(run)` says how many there are: Start = veterans then Start; Debrief = candidates then Continue; End = one row (restart).
- **Menus:** only the edge-triggered `menuUp/menuDown/menuSelect/menuBack` actions (compared with `world.prev.menu*`) change anything, so replays record every choice. Up/down wrap. Start: select ticks/unticks a veteran, or on the Start row begins the run. Debrief: select takes the highlighted candidate (one pick, then only Continue is left) or Continue; B rests the cursor on Continue (skip). End: select restarts at the Start screen.
- **World gating:** while the phase is not `battle` (and the mode is `run`) `stepWorld` runs `stepRun` and the button edges and nothing else: the world holds still. The respawn key does nothing in a run.
- **Battle:** `startBattle` clears the field (the ship back at the centre, shots, locks, fighters and pods gone; the squadron is rebuilt from the active pilots, which restores their hp) and creates only that battle's turrets (`turretsIn`). `stepRunBattle` replaces the practice waves: `wavesIn` waves of `waveSizeIn` fighters (`waveDelay` apart), the battle is won when the last wave is down, then debrief (hull restored, pilots credited a battle) or, after the last battle, victory. It also charges `stats.hitsTaken` to `hull` (an evade roll still protects); hull 0 = defeat. A run-mode world with `battle` 0 (tests) keeps the practice waves.
- **Start:** the ticked veterans join first (`PilotJoined how: 'veteran'`), then generated pilots fill the squad up to `startingSquad`.
- **Events:** `BattleStarted`, `WaveStarted`, `BattleCleared`, `RunEnded`.
- **Parameters:** `data/tuning/run.ts`.
