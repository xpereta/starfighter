# render/spectacle

- **Purpose:** the render-only "more spectacular" layer of a style pack. A pack opts in with an optional `spectacle` section in its `StyleInput` (contract and validation: `../spectacle-contract.ts`; every sub-section is optional, complete when present, and a pack inherits sections from its parent). Packs without it (`plain`, `anime-80s`, `realistic`) are drawn exactly as before. The shipped user is `data/styles/anime-spectacle/` (parent `anime-80s`), selected with `?style=anime-spectacle` (`&dev` for the panel).
- **Reads:** the active style (`activeStyle().spectacle`), world state and the events of each step. **Writes:** nothing in core. Own seeded random streams only; the replay hash is identical under every style (`tests/sim/style.sim.test.ts` runs the effects over every step).
- **Quality:** `?fx=low|medium|high` (high by default; remembered when set in the panel's Spectacle section). Presets in `data/spectacle-quality.ts` (pool caps, post on/off, bloom resolution, MSAA). `low` is the fallback: no post-processing, no shader clouds, small pools. All effects live in fixed pools with hard caps.
- **Post-processing (`post.ts`, `post-state.ts`):** an `EffectComposer` (render, `UnrealBloomPass`, one finishing shader pass for colour fringe, vignette, scanlines, grain and the zoom punch, `OutputPass`). The finishing pass runs in linear colour so the picture matches the plain render. It falls back to the plain render without console errors when the GPU lacks float render targets, when the composer throws, when `?fx=low`, or when the panel switches it off. The transient part (hit pulse, punch) is pure and tested (`post-state.ts`).
- **Panel:** the Spectacle section (`src/dev/panel-spectacle.ts`): quality level, a switch per effect group, overall intensity, and a slider for every number of the pack's spectacle (`panel-spectacle-logic.ts`). Edits change the resolved pack in memory only.
- **Test:** `spectacle-contract.test.ts` (validation, inheritance, no write-through), `post-state.test.ts` (pulse, punch, neutral, quality levels), `panel-spectacle-logic.test.ts`, `tests/e2e/spectacle.spec.ts` (loads at every level without console errors, panel section), plus the generic style checks over every pack.
